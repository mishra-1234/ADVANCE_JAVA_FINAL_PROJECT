# ADVANCE_JAVA_PROJECT

A full-stack web application featuring an **Angular** frontend and an **Advanced Java / Jakarta EE (Maven & Smart Tomcat)** backend, providing user authentication and dashboard management.

---

## 🚀 Features

- **User Authentication:** Secure user signup and login workflows.
- **Dashboard:** Interactive dashboard view for authenticated users.
- **Full-Stack Architecture:** Decoupled Angular client interfacing with Java backend endpoints.
- **Tomcat Integration:** Pre-configured deployment support via Smart Tomcat.

---

## 🛠️ Tech Stack

### Frontend
- **Framework:** Angular
- **Language:** TypeScript, HTML5, CSS3 / SCSS
- **Package Manager:** npm

### Backend
- **Core:** Java (Advanced Java / Jakarta EE)
- **Build Tool:** Apache Maven (`pom.xml`)
- **Server:** Apache Tomcat (configured via `.smarttomcat`)
